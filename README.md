# お金のたね

こどもNISAに入れたお金が18さいまでにどうなるかを、ゲームでためす子ども向けシミュレーター（10〜13歳くらい向け）。
見た目は `nisa-quiz`（とうしクイズ 110）、つくりは `edu-cost-sim`（教育費シミュレーター）にそろえている。

## あそびかた

- **そだてる**：何さいから・はじめに入れるお金・毎年たすお金・カゴ（世界ぜんぶの株／アメリカの株／バランス）を選び、1年ずつすすめる。
  1年で15%以上へると「へっちゃった！どうする？」が出る。売るとそこから先は ちょきん箱 になり、グラフに「もし売らずにもっていたら」の点線が出る。
  18さいで「つかう」か「60さいまで おいておく」かを選ぶ。
- **100回くらべる**：同じ100とおりの未来で、3つのカゴと ちょきん箱 を点のグラフでくらべる。18さい・30さい・60さいで切りかえられる。
- **ひみつのルール**：72のルール（スライダー）、分散、ゆれ、売らないやくそく、こどもNISAのきまり。「おうちの人へ」に数字の前提。

入力とけっかの記録は、その端末の localStorage にだけ保存する。家族の情報はコードに入れていない。

## 動かす

ビルドなし。HTML と JavaScript をそのまま置くだけで動く（Chrome / Safari / iPhone）。

```bash
python -m http.server 8772 -d okane-tane
```

計算のテストはブラウザで `tests.html` を開く（タイトルに PASS n/n が出る）。

## 構成

```text
index.html / style.css / manifest.json / sw.js / icon.svg / icon-*.png / robots.txt
js/domain/   計算（画面に依存しない純粋関数）
  random.js    シードつき乱数（mulberry32）と正規乱数
  baskets.js   カゴの数字・こどもNISAのきまり（数字はすべてここ）
  simulate.js  1本の未来、100回くらべる、まとめ、72のルール
js/storage.js  localStorage（try/catch つき）
js/chart.js    お金の変化の線グラフ・100回の点グラフ（SVG、ライブラリなし）
js/app.js      画面
tests.html / tests/simulate.test.js
```

## 値動きのモデル（学習用の仮定）

- 毎年、すべてのカゴに共通の「世界のできごと」（正規乱数 z と、5%の確率の「大きく下がる年」）を1つ引く。
- 大きく下がる年の中心：世界 −35%・アメリカ −38%・バランス −18%。
- ふつうの年の中心は、長い目で見たまんなかの伸びが 世界 5%・アメリカ 5%・バランス 3% になるように決める（テストで確認）。
- 1年のゆれ（標準偏差）はおよそ 世界 18%・アメリカ 21%・バランス 9%。ちょきん箱は年0.2%で固定。
- 為替・信託報酬は分けて入れていない。NISAなので税金なし。

## こどもNISA のきまり（2026年11月時点の公表内容）

2027年1月開始。0〜17歳。つみたてのみ。年60万円・合計600万円。12歳になるまでは災害時のみ非課税で払い出し、
12歳からは子どものための教育費・生活費に本人の同意つきで払い出し。18歳で成年のつみたて投資枠へ移行。
制度が変わったら `js/domain/baskets.js` の `OT.NISA` と、`index.html` のルール画面の文を直す。

## 注意

学習用のおおまかな仮定で、将来の運用成果を示すものではない。投資の助言ではない。
